# P2P Screen Share (Android)
Build the APK without Android Studio:
1. Create a new GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the Actions tab -> "Build APK" -> wait for the green check.
3. Open the run -> Artifacts -> download P2PScreenShare-apk -> unzip -> install app-debug.apk.
Or in Android Studio: open this folder, Build > Build APK(s).
Viewer: open screenshare.html on any PC/phone -> "Watch a screen".
